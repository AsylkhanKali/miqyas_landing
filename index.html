Features

Everything a PM needs.
Nothing they don't.

🔍

AI Deviation Detection

Mask2Former identifies elements across 13 construction categories. IoU scoring flags behind, ahead, and not-started elements automatically — no manual annotations.

📅

Critical Path Analysis

Deviations are cross-referenced with your P6 schedule. A delay on a float-rich beam is noise. The same delay on the core wall is a crisis. We tell you which is which.

Interactive 3D BIM Viewer

Real IFC geometry in Three.js — not bounding boxes. Click any element to inspect IoU score, deviation status, and linked schedule activity. Toggle by level or category.

Procore Integration

OAuth2 connect, configure field mapping once, then bulk-push deviations as RFIs or Issues in one click. Full audit trail on both sides.

FAQ

Common questions

What BIM formats do you support?
Any valid IFC 2x3 or IFC 4 file via IfcOpenShell. Revit, ArchiCAD, Tekla, Navisworks — if it exports IFC, it works.
Do I need a 360° camera specifically?
360° gives the best per-walk coverage, but the pipeline accepts standard video. More frame overlap = higher IoU confidence scores.
How long does analysis take after upload?
Typically 15–40 minutes. Frame extraction, COLMAP, segmentation, and comparison run in parallel via GPU workers. You get notified when done.
How does the Procore integration work?
Connect via OAuth2 (under 2 minutes). Map fields once. Then bulk-push any deviation report to Procore as RFIs with a full audit trail.
What schedule formats are supported?
Primavera P6 XER and XML. Parser reads PROJECT, PROJWBS, TASK, TASKPRED — activities, WBS, predecessors, and float extracted automatically.
How accurate is deviation detection?
With good 360° coverage, IoU above 0.7 is typical for well-modeled elements. Every result includes a per-element confidence score.
Can stakeholders view without an account?
Read-only investor links are on the Pro roadmap. For now, share PDF reports or the executive summary. Shareable live links planned for Q3 2025.
What's the typical ROI?
One prevented critical-path delay typically covers months of cost. Case study projects report $200K–$500K in avoided recovery costs per catch.
